# VYBINKA — исправление кнопок

Исправлена причина, из-за которой интерактивные элементы могли не реагировать на Android/touch.

Главная проблема предыдущего чёрного архива: `index.html` подключал `/vkb_fixes.js`, но самого файла в архиве не было. Добавлен совместимый слой v5, который повторно привязывает динамически создаваемые кнопки и inline-обработчики после каждого рендера.

Также добавлен `button_runtime.js` для диагностики ошибок JavaScript.

Проверены клиентские обработчики для:
- профиль / редактирование / настроение / конфиденциальность;
- поиск по @username;
- нравится / не нравится / просмотр профиля;
- создание групп;
- создание каналов;
- открытие каналов;
- чаты и меню чатов;
- подарки и баланс;
- рулетка;
- нижняя навигация.

API создания групп (`POST /api/groups`) и каналов (`POST /api/channels`) присутствуют на сервере.
