**VYBINKA** — это место для общения, знакомств, профилей, музыки, настроения и подарков.

🌐 **Открыть VYBINKA:** https://vaybinka.onrender.com/

## Что здесь можно делать

- создать свой профиль и заполнить информацию о себе;
- поставить аватар и изменить профиль;
- выбрать текущее настроение;
- добавлять музыку в профиль;
- общаться с другими пользователями;
- отправлять и получать виртуальные подарки;
- собирать свою коллекцию подарков;
- использовать **♥ Сердца** — внутреннюю валюту VYBINKA;
- получать ежедневные бонусы;
- добавлять понравившиеся подарки в избранное;
- управлять настройками конфиденциальности;
- делиться своим профилем.

## ♥ Сердца

**Сердца** — внутренняя валюта VYBINKA. Она используется для отправки виртуальных подарков.

Количество Сердец отображается в профиле и в разделе подарков. Перед отправкой подарка приложение показывает его стоимость, поэтому случайно потратить валюту сложнее.

## 🎁 Подарки

В VYBINKA есть обычные, редкие, легендарные и секретные подарки. Каждый подарок имеет собственную стоимость в Сердцах.

Полученные подарки можно увидеть в своей коллекции профиля.

## 👤 Профиль

В профиле можно изменить:

- имя;
- описание о себе;
- аватар;
- настроение;
- музыку;
- другие доступные сведения профиля.

## 🎵 Музыка

Можно добавить собственный аудиофайл в профиль. Посетители профиля смогут увидеть музыкальный блок, если он разрешён настройками конфиденциальности.

Загружайте только музыку и аудио, на использование которых у вас есть права.

## 🔒 Конфиденциальность

В настройках можно управлять видимостью профиля, музыки, активности и сообщений в соответствии с доступными параметрами приложения.

Не публикуйте в профиле пароль, адрес проживания, документы или другие личные данные, которые не хотите показывать другим пользователям.
