# VYBINKA 1.0.4 — production-ready full-stack build

Это полноценная серверная версия VYBINKA, а не localStorage-демо: SQLite хранит аккаунты, сессии, лайки, блокировки, чаты, сообщения, группы, каналы и жалобы; WebSocket доставляет новые сообщения в реальном времени; Multer принимает медиа; SMTP может отправлять жалобы; Mistral подключается через сервер.

## Запуск
1. Установите Node.js 20+.
2. `npm install`

В архиве уже подготовлен `.env` для серверной Лили; ключ не используется в браузере.
3. Скопируйте `.env.example` в `.env` и заполните нужные значения.
4. `npm start`
5. Откройте `http://localhost:19393`.

Для настоящего Mistral задайте `MISTRAL_API_KEY` на сервере. Ключ не попадает в браузер.
Для почты жалоб задайте SMTP-параметры. Даже без SMTP жалоба сохраняется в SQLite.

## Данные
- `data/vybinka.sqlite` — база.
- `uploads/` — пользовательские аватары, обложки, музыка и медиа чатов.

## Безопасность 10+
- Возраст регистрации: 10+.
- «Отношения (18+)» недоступны несовершеннолетним.
- Система не показывает скрытый внутренний ID другим пользователям.
- Жалобы и блокировки серверные.
- Не храните API-ключи в `public/`.

Перед публичным запуском рекомендуется поставить HTTPS/Reverse Proxy, резервное копирование SQLite и ограничение размера файлов на уровне инфраструктуры.


## Реальные платежи
Покупка сердец больше не использует demo endpoint. Используется Stripe Checkout; начисление выполняется сервером только после webhook `checkout.session.completed`. Нужны `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` и `PUBLIC_URL`. Выплаты Stripe настраиваются в Stripe Dashboard на банковский счёт; реквизиты карты пользователей на сервер не сохраняются.
