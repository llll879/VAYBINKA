# VYBINKA — исправление кнопок и меню

## Что исправлено
- Кнопки профиля теперь обрабатываются корректно на Android.
- Исправлены кнопки покупки сердец: аргументы вроде `100`, `500`, `1000` и `5000` больше не теряются.
- Исправлено открытие каналов.
- Исправлена кнопка поиска.
- Все действия с формами переведены на встроенные модальные окна сайта.
- Создание канала теперь открывает форму внутри VYBINKA: название, @username и описание.
- Создание группы тоже выполняется через форму VYBINKA.
- Выбор получателя подарка выполняется через форму сайта.
- Жалобы, редактирование и удаление сообщений больше не используют браузерные `prompt/confirm`.
- Выдача подарков из админ-панели теперь использует меню сайта.
- Обновлены версии JS в HTML, чтобы старый кеш браузера не возвращал сломанную версию.
